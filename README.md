# ghostty-nightly-bin

Arch Linux PKGBUILD for [Ghostty](https://ghostty.org/) nightly binary packages (x86_64). GitHub Actions builds and uploads the latest tip commit to [GitHub Releases](https://github.com/jpenilla/ghostty-nightly-bin) nightly. AUR sync is also automated through GHA. Manual intervention is only needed when the PKGBUILD changes (a manual action trigger is required, otherwise it will correct itself the next day).


Packages are split to follow conventions of other Arch Ghostty packages:

- `ghostty-nightly-bin`
- `ghostty-shell-integration-nightly-bin`
- `ghostty-terminfo-nightly-bin`
